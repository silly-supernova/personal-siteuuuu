#  Personal Portfolio Website

A minimalist,fully responsive 3-section personal portfolio website built from scratch using HTML and CSS. 

---

##  Live Demo
* **Live Website:** [View Portfolio Live](https://silly-supernova.github.io/personal-siteuuuu/)
* **Repository:** [GitHub Repository](https://github.com/silly-supernova/personal-siteuuuu)

---

##  Features
* **Intro Section:** Clean introductory layout establishing identity and focus.
* **Interests Section:** Highlights personal passions, hobbies, and a constant rotation of favorite indie/alt rock music inspirations.
* **Connect Section:** Direct communication links.
* **Responsive Design:** Styled cleanly using CSS Flexbox for seamless viewing across mobile and desktop displays.

---

## Tech used
* **Markup:** HTML5 (Semantic Structure)
* **Styling:** CSS3 (Custom Layouts, Flexbox, Typography)
* **Version Control:** Git & GitHub / GitHub Codespaces
* **Hosting:** GitHub Pages
